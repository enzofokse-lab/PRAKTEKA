### Описание логики

Программа предназначена для расчета времени, необходимого архивному сканеру на оцифровку древних текстов. Пользователь вводит объем текста в символах и скорость работы сканера. Система рассчитывает время в минутах, обязательно округляя результат **в большую сторону** (так как даже неполная минута работы требует учета полного временного интервала).

**Формула расчета:**

$$ Время (мин) = \lceil \frac{Объем (симв)}{Скорость (симв/мин)} \rceil $$

*Где $\lceil x \rceil$ — функция округления вверх (ceiling).*

*Для целочисленных данных используется оптимизированная формула без плавающей точки:*
`Time = (Volume + Speed - 1) / Speed`

*Также реализована защита от ввода некорректных данных (буквы, отрицательные числа, нулевая скорость).
